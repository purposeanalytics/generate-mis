# generate-mis

## OHRS reference documentation

The Ontario Healthcare Reporting Standards (OHRS) are available as Markdown in the sibling private repo `../pa-ohrs-to-markdown/md/<fiscal-year>/` (e.g. `2026-27` = OHRS v13.1). Folder names are the fiscal year the version applies to.

- Check the relevant fiscal year's OHRS before changing logic for functional centres, primary/secondary accounts, statistical accounts, or fiscal-year rules. Cite the section you relied on.
- Search with Grep, not by reading whole files. The chapters are long.
- If the folder is missing, the user hasn't cloned the private repo. Say so; don't guess at OHRS rules.
- This repo is public. Don't copy OHRS text into code, comments, commits, or docs here beyond brief references to section numbers.
